CadastroDesktop

Projeto Java Desktop desenvolvido para realizar o cadastro e o gerenciamento de clientes. O sistema permite cadastrar, consultar, editar e inativar registros, com validação dos campos obrigatórios e armazenamento protegido da senha por hash e salt.
A estrutura utiliza uma janela principal com telas em JPanel, permitindo a inclusão futura de novos módulos e de uma tela de login.
